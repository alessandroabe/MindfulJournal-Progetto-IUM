# Mindful Journal - Progetto IUM 🌱

Mindful Journal nasce dall’esigenza, sempre più diffusa, di gestire stress e ansia nella vita moderna. L’app offre uno spazio digitale riservato per l’auto-riflessione quotidiana, aiutando a monitorare il proprio benessere psicologico attraverso esercizi, diario e strumenti di consapevolezza. 🧘‍♂️💡

---

## Funzionalità principali ✨

- **Registrazione giornaliera dello stato emotivo** 😃😐😢  
  Ogni giorno puoi loggare la tua emozione scegliendo un’emoji rappresentativa e, se vuoi, aggiungere una riflessione (libera o guidata).

- **Riflessioni guidate e libere** 📝  
  Durante la registrazione puoi scegliere tra scrivere una riflessione libera oppure seguire uno spunto di riflessione guidata, rispondendo a domande presentate dal sistema.

- **Diario** 📅📒  
  Accedendo alla sezione “Diario”, visualizzi subito la vista giornaliera di oggi, con dettagli su emozione, eventuali tag di contesto e riflessione inserita.  
  Da qui puoi cliccare sull’icona calendario per aprire la vista mensile, che mostra tutti i giorni del mese (e mesi precedenti) con le emoji registrate; cliccando su un giorno, torni alla relativa vista giornaliera.

- **Profilo utente** 👤  
  Personalizzazione basilare dell’esperienza.

## Come testare il prototipo 🖥️

1. Clona la repository o scarica i file del progetto.
   ```bash
   git clone https://github.com/alessandroabe/MindfulJournal-Progetto-IUM.git
   ```
2. Apri il file [`html/register.html`](html/register.html) nel browser.
3. Clicca sulla freccia in alto a sinistra per tornare alla pagina di login (`login.html`).
4. Nella pagina di login, clicca semplicemente su “Accedi” per simulare l’accesso.
5. Ora puoi esplorare liberamente le funzionalità e la navigazione tra le pagine.

> ℹ️ Nota: Questo è un prototipo statico, senza backend o database. Le funzionalità sono simulate solo a livello di interfaccia.
